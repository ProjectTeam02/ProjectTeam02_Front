## 이번 보완

로그인·로그아웃·진단 요청이 리다이렉트를 자동 추적하지 않게 했습니다. 실제 307/308 테스트 서버로 인증 정보 재전송이 없는지 검사합니다. 미배포 API/깨진 응답/시간 초과/네트워크 실패를 구분하며 빈 데이터로 바꾸지 않습니다.

가짜 비밀번호 변경·구매/장착 완료와 개발용 갤러리·예시 문제·로컬 AI 중계는 제외합니다. 직업 저장 콜백이 없으면 저장을 막습니다. 정식 일반 퀴즈는 서버 채점·저장·보상 응답만 사용하고 동일 답안 재시도에 같은 중복 방지 키를 보냅니다. AI 생성 요청은 기본 차단합니다.

## 운영 서버 읽기 확인

앱과 같은 서비스 함수로 `GET /health`는 UP, `GET /api/v1/health/dependencies`는 DB CONNECTED / AI DISCONNECTED / DEGRADED임을 확인했습니다. HTTP 200을 AI 정상 연결로 표시하지 않습니다. 토큰 없는 `/api/v1/topics`는 401이며 인증 필요로 구분합니다.

브라우저 CORS 사전 요청은 `http://localhost:3001`과 `Authorization, Content-Type, Idempotency-Key`를 허용했습니다. 계정 생성·답안 저장·유료 AI 생성 요청은 실행하지 않았습니다. 운영 계정으로 로그인부터 완료까지 성공했다는 검증은 이번 결과에 포함하지 않습니다.
