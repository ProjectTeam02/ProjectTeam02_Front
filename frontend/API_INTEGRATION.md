# API 연결 범위

2026-11-10 한국 시간 기준 프론트 코드의 연결 범위입니다. 운영 계정의 전체 동작 성공이나 서버 배포 완료를 뜻하지 않습니다.

| 영역 | 프론트 구현 | 남은 확인/기능 |
|---|---|---|
| 계정 | 이메일 회원가입·로그인·로그아웃, PC 웹 카카오 PKCE | 운영 카카오 설정, 모바일 복귀, 토큰 갱신/영구 보관, 비밀번호 재설정 |
| 회원 | 회원·성장·지갑·현재 직업/장착 조회 | 프로필/직업 변경, 전체 보유 목록, 구매/장착 |
| 학습 | 주제·단계·개념 조회, 일반 응시/복원·제출·서버 채점·결과 | 운영 공개 콘텐츠/문항, 보스 응시, 복습 저장 |
| 이력·일정 | 이력 목록/상세, 월/날짜 달력, 일정 추가·수정·삭제 | 실제 학습 대상이 있어야 일정 생성 가능, 전체 대상 선택 보완 |
| 알림 | 켜기/끄기 저장 | 저장값 조회, 시간 변경, 기기 권한/실제 알림 발송 |
| 튜터 | 대화 목록·생성·메시지 이력·사용량·전송 코드 | AI 서버 연결, 실제 답변/출처 전체 검증; 생성은 기본 차단 |

API origin은 `.env.example`의 HTTPS 서버를 사용합니다. 인증 요청은 HTTPS 또는 localhost loopback만 허용하고 리다이렉트 자동 재전송을 거부합니다. JWT는 메모리에 보관하며 재시작 후 재로그인이 필요합니다. 화면 이동/조건 변경 시 조회를 취소하고 이전 계정 데이터를 숨깁니다. 쓰기 요청은 자동 재시도하지 않습니다.

조회 성공의 빈 배열/null은 데이터 없음, 미구현 경로는 API 미연결, 401은 로그인 필요, 다른 서버/통신/응답 형식 오류는 요청 실패로 표시합니다. 정확히 일치하는 승인 문항 없음 응답만 빈 문항으로 판정합니다.

학습은 [LEARNING_INTEGRATION.md](LEARNING_INTEGRATION.md)를 참고하세요. 실제 AI 생성은 `EXPO_PUBLIC_AI_REQUESTS_ENABLED=false`로 차단합니다. 상태 조회·대화 목록·이미 저장된 일반 퀴즈 응시/채점은 생성 요청과 구분합니다.

개발용 학습 JSON/로더·화면 갤러리·가상 구매/비밀번호 재설정 완료·로컬 AI 중계는 main 통합에서 제외합니다. 과거 로컬 검증의 상세는 기존 대화 기록에 있으며 이번 검사 결과는 [MAIN_INTEGRATION.md](MAIN_INTEGRATION.md)에 기록합니다.
