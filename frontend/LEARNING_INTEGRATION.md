# 정식 학습·일반 퀴즈 연결

확인일: 2026-11-10 (한국 시간)
대상: 이 저장소의 `frontend/`

## 연결 범위

이메일 로그인 → 홈의 **경제 학습 시작하기** 또는 **탐험** 탭 → 주제 선택 → 단계 선택 → 개념 카드 → **퀴즈 시작 화면으로** → **퀴즈 시작·이어하기** → 답안 제출 → **저장된 결과 보기**.

정식 화면은 EC2의 실제 UUID·잠금·진행도·문항·채점·해설·보상 지급 여부를 사용합니다. 서버가 빈 목록을 반환한 경우와 인증 실패·데이터 구성 오류를 구분합니다. 로컬 예시 자료로 대신 채우지 않습니다.

| 동작 | API (`/api/v1` 기준) |
|---|---|
| 공개 주제 | `GET /topics` |
| 단계·서버 잠금·완료 상태 | `GET /topics/:topicId/stages` |
| 단계 상세·연결 개념 | `GET /stages/:stageId` |
| 개념 카드 | `GET /concepts/:conceptId` |
| 일반 응시 시작/이어하기 | `POST /quizzes/stages/:stageId/attempts` (본문 없음) |
| 현재 응시 복원 | `GET /quizzes/attempts/:attemptId` |
| 서버 채점·진행·완료·보상 저장 | `POST /quizzes/:questionId/submit` (`choiceId`, `attemptId`, `Idempotency-Key`) |
| 저장된 결과 | `GET /quizzes/attempts/:attemptId/result` |
| 현재 성장·코인 | `GET /users/me` |

같은 응시·문항의 답안을 재전송할 때 같은 중복 방지 키를 보냅니다. 통신 오류가 나면 첫 답을 유지해 재시도하거나 서버의 현재 응시를 다시 조회할 수 있습니다. 제출 전에는 정답·해설을 화면 모델에 보관하지 않습니다. 마지막 제출의 완료·보상 저장은 백엔드가 처리합니다. 프론트에서 임의 보상을 더하거나 별도 완료 요청을 만들지 않습니다.

## 실제 서버로 실행

프론트 `.env`는 다음 설정을 유지합니다.

```dotenv
EXPO_PUBLIC_API_URL=https://lerenapp.com
EXPO_PUBLIC_AI_REQUESTS_ENABLED=false
```

```powershell
cd frontend
npm.cmd start -- --go --lan --clear
```

실행 중인 프론트가 있으면 같은 VS Code 터미널에서 종료 후 재실행합니다. 로컬 백엔드·AI·DB는 필요하지 않습니다. PC 웹 또는 같은 네트워크의 Expo Go에서 EC2 계정으로 이메일 로그인합니다. 카카오는 별도 서버 설정 작업입니다.

일반 퀴즈는 이미 저장된 문제를 조회·채점하므로 AI 모델 요청을 실행하지 않습니다. 튜터 등 실제 AI 생성 요청은 위 설정으로 계속 차단합니다.

## 검증 결과와 한계

- 타입 검사·lint 통과, 자동 계약/회귀 검사 69개 통과.
- 실제 백엔드 코드와 격리된 PostgreSQL 18로 주제·단계·개념 카드·응시·채점·결과 연동 확인.
- 정답 2개로 통과, 최초 보상 EXP·코인 저장, 같은 답안 재전송 시 중복 보상 없음 확인.
- 오답 3개로 실패, 추가 보상 없음, 이전 통과 진행도 유지 확인.
- 브라우저에서 이메일 로그인부터 학습 완료·서버 성장/코인 표시까지 직접 조작 검증.
- iOS·Android 전체 개발 번들 생성 성공. 실제 휴대폰 조작은 미검증.
- 실제 EC2의 CORS가 `Idempotency-Key`를 허용하는 것은 확인. 이번 검증에서 운영 계정 생성·학습 답안 저장·AI 호출은 하지 않음.
- EC2 인플레이션 콘텐츠·문항의 실제 저장 상태와 운영 계정의 전체 학습 성공은 미확인. 위 성공 결과는 격리 DB에서 검증한 결과임.

## 서버 데이터 준비 조건 / 남은 기능

공개(PUBLISHED) 주제·단계·개념/카드, 일반 단계에 배정된 공개 문항 3개(각 선택지 4개·정답 1개), 보상 및 레벨 기준 데이터가 필요합니다. 이전 단계나 선수 주제 조건도 서버가 판정합니다. 문제 풀이 시작 시 503과 문항 구성 안내가 나오면 데이터 준비를 확인해야 하며 AI 미연결로 단정하면 안 됩니다.

현재 백엔드는 일반 단계 응시만 지원하므로 보스 퀴즈는 시작을 막고 안내합니다. 복습 시안, 일정의 전체 학습 대상 선택, 카카오 앱 로그인, 백엔드↔AI 연결 및 실제 AI 답변은 이번 범위와 별도입니다. 새로고침/앱 재실행 후 메모리 로그인은 다시 필요하며, 저장된 응시는 해당 단계의 이어하기로 조회합니다.

위 검증 결과는 이전 작업 대화에서 수행한 격리 환경 검증 기록입니다. 이번 main 통합의 재검사 결과는 [MAIN_INTEGRATION.md](MAIN_INTEGRATION.md)에 별도로 기록합니다. 운영 DB·AI 설정은 이번 프론트 통합에서 변경하지 않습니다.
